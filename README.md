# StudioBook

**Real problem:** freelancers waste unpaid hours on under-budget clients and vague briefs.

**Solution:** a client intake wizard that scores lead quality, rejects work below a safe budget/rate floor, recommends a package quote, and generates a scope document before the call. **No account needed.**

- “Is this lead worth a call?”
- “What should I quote without going under €17.50/hr?”
- “How do I write a clear scope fast?”
